# ACY Instagram IB Outreach, the n8n brain

This folder is the source of the n8n workflow **ACY Instagram IB Outreach**
(`https://wizu22.app.n8n.cloud/workflow/LKBSE832cqH09x6u`) and the five data tables it uses.

## What n8n does and what it cannot do

n8n runs on a server. It has no access to Baha's Chrome, his Instagram login, the
`localStorage` history map, or the Instagram page. So the split is:

| Browser side (Claude in Chrome, Baha's Instagram) | n8n side (this workflow) |
| --- | --- |
| Open profiles, read bio, links, last 12 posts | Hold every rule and list |
| Open `/m/<username>/`, run the thread gate, paste, click Send, re-check | Decide skip / reject / weak / candidate |
| Reply check on the inbox, window title, yellow bar, visibility check | Ask Claude to judge the profile and extract 3 details |
| | Write the Jordanian opener and enforce its format |
| | Count the daily cap, remember who was contacted |
| | Log sends, rejections, flags; build the report |

The browser side calls the webhook before and after each step. `operator-prompt.md` is the
text to paste into Claude in Chrome so it uses the webhook.

## Webhook

`POST https://wizu22.app.n8n.cloud/webhook/acy-outreach` with a JSON body. `action` picks the route.

### `check`

```json
{"action":"check","username":"gold_trader_jo","full_name":"أحمد","bio":"...","followers":12400,"posts":88,
 "is_private":false,"follow_relation":"none","country":"Jordan",
 "links":["https://t.me/..."],
 "recent_posts":[{"date":"2026-10-01","caption":"..."}],
 "notes":"anything else seen on the page"}
```

`follow_relation` is `none`, `following` (Baha follows them) or `follow_back` (they follow Baha).
Both of the latter mean skip.

Response: `verdict` is one of `skip`, `reject`, `weak`, `cap`, `lead`, `error`, with `reasons[]`,
`remaining_today`, and for a lead: `display_name`, `addressee` (man, woman, team), `broker`, `details[]`.

Order inside the workflow: do-not-contact table, history table, 24 hour send count, rule rejects
(prop firms, copy trading, account management, bots, binary options, guarantees, MLM, local stock
markets, Sudan and Yemen), sanity checks (400 to 400,000 followers, 12 posts, not private, not
dormant, Arabic present), then Claude for the judgment and the three details.

### `opener`

```json
{"action":"opener","username":"gold_trader_jo","name":"أحمد","addressee":"man","broker":"",
 "details":["...","...","..."],"extra":""}
```

Response: `message` (exactly five paragraphs, eight line breaks), `valid`, `problems[]`.
If `valid` is false after the automatic rewrite, do not send. Fix the details and call again.

### `log_send`

```json
{"action":"log_send","username":"gold_trader_jo","thread_id":"1234567890","why":"paid Telegram channel, Exness IB link","message":"..."}
```

Writes to `acy_sends` and marks the username in `acy_history`. Only call this after the chat was
reloaded and the message was seen with its eight line breaks.

### `log_reject`

```json
{"action":"log_reject","username":"x","reason":"copy trading","stage":"profile"}
```

Stages: `inbox`, `profile`, `thread`, `send`. Put Instagram's own words in `reason` when a send
fails ("Failed to send", "Couldn't send", "Not sent", 429) so the report lists it as a blocker.

### `flag`

```json
{"action":"flag","username":"x","kind":"reply","note":"voice note from them"}
```

Kinds: `reply`, `voice_note`, `follow_up` (Baha messaged, no answer), `other`.

### `report`

```json
{"action":"report","target":20,"problems":["Instagram window was hidden for twenty minutes"]}
```

Returns `report` (text, number first, problems first, Arabic in its own block) and `counts`.
Optional `since` (ISO date) widens the window.

### `import_history`

```json
{"action":"import_history","__acy_H22": "<the JSON string from localStorage>", "__acy_hist": "<the JSON string>", "source":"localStorage"}
```

Also accepts `usernames: [...]`. Run once. Everything in the map is then a skip.

## Data tables (n8n project of Baha)

| Table | Columns | Purpose |
| --- | --- | --- |
| `acy_dnc` | username, list, note | Seeded with the do-not-contact list, friends, recent sends, Baha's own follow-ups, iTradePro and Papa Forex |
| `acy_history` | username, source, note | The history map, any hit means skip |
| `acy_sends` | sent_at, username, thread_id, why, message | One line per verified send, also the daily cap source |
| `acy_rejections` | at, username, reason, stage | One line per rejection |
| `acy_flags` | at, username, kind, note | Replies, voice notes, follow-ups for Baha |

Add a name to `acy_dnc` in the n8n UI to block it forever.

## Files

- `workflow.sdk.ts`: the workflow in n8n Workflow SDK form, generated by `build_workflow.py`.
- `code/*.js`: the Code node scripts, one file per node. `node code/test_local.js` runs them with
  mocked n8n helpers.
- `prompts/*.md`: the system prompts for the qualification and opener Claude nodes.
- `operator-prompt.md`: what to paste into Claude in Chrome.

To change a rule: edit the file, run the tests, run `python3 acy-outreach-n8n/build_workflow.py`,
and paste the new `workflow.sdk.ts` into n8n (or re-create through the n8n MCP tools).
